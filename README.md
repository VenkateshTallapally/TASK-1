# Sum Two Numbers in Java

This is a simple Java program that takes two numbers as input from the user and calculates their sum.

## Features
- Takes user input using Scanner
- Adds two integer numbers
- Displays the sum as output

## Technologies Used
- Java
- Scanner Class

## Project Structure

```bash
SumTwoNumbers.java
```

## How It Works
1. User enters the first number
2. User enters the second number
3. Program adds both numbers
4. Displays the result

## Sample Output

```bash
Enter first number: 10
Enter second number: 20
Sum: 30
```

## How to Run

1. Compile the program:
```bash
javac SumTwoNumbers.java
```

2. Run the program:
```bash
java SumTwoNumbers
```
